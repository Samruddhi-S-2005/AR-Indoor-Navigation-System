# AR Indoor Navigation System

An Augmented Reality (AR) based indoor navigation mobile application developed using Unity and ARCore to help users navigate indoor environments interactively and efficiently.

---

## 📱 Project Overview

Traditional GPS-based systems are not effective for indoor navigation. This project provides an AR-powered solution that guides users inside buildings using real-time augmented reality directional assistance.

The application overlays navigation paths and directional indicators in the real-world environment through a mobile device camera, creating an interactive navigation experience.

---

## 🚀 Features

- Indoor route navigation using AR
- Real-time directional guidance
- Interactive mobile application
- User-friendly navigation interface
- AR visualization using smartphone camera
- Efficient indoor path assistance
